How it works

1
Create a prompt template
Click + in the sidebar to create a new prompt. Give it a name, then write your template text in the Editor. Use {{}} anywhere you want a fillable placeholder — you can add as many as you need.
2
Fill in the values
Each {{}} in your template generates a numbered input field below the template. Type your values into these fields — the Output panel on the right updates instantly as you type.
3
Copy the output
Once you're happy with the filled-in result, click Copy in the Output panel to copy the complete prompt to your clipboard, ready to paste anywhere.
4
Save & organise
Press Save (or Ctrl+S) to persist your prompt. Prompts are stored in your browser's localStorage. You can drag to reorder them in the sidebar, search by name or content, and export/import them as .md files for backup.
5
Export for backup
Use the ↓ (download) button in the topbar or sidebar to export individual prompts, or use Export all to download every prompt as a single prompts-export.md file. Import it back anytime using the ↑ button.
